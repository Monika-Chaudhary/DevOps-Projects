# Deploy Java Application on Kubernetes 

Pre-requisite:
i. Docker
ii. Git
iii. Minikube
iv. Maven

Steps:-
i. Checkout code from GitHub
ii. Build code using Maven so will create war/ear
iii. Will copy war/ear to Docker build to create docker image
iv. Push docker image to DokerHub
v. Pull image from DockerHub to deploy on Kubernetes (here we use minikube)
